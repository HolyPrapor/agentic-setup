# /gm

Interview me relentlessly about every aspect of my task until we've reached a shared understanding. Walk down each branch of the design tree, resolving dependencies between decisions. For each question, provide your recommended answer.

Guidelines:

- Try to ask independent questions in batches, though asking one at a time is acceptable if it's more appropriate for the specific context.
- If a question can be answered by exploring the codebase, explore the codebase instead.
- Use the structured user-input tool for asking questions when one is available; otherwise ask directly in text.
